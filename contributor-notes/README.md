# Contributor references

These are task-specific references, not eager instruction imports.

- `release.md`: release preparation and distribution checks. Root instructions
  keep the cross-area triggers and the requirement for explicit tag approval.
- `agent-history.md`: previous root instructions preserved verbatim on
  2026-10-16. Use for a specific incident or recovery recipe; current root
  instructions and area references remain authoritative.

Public references contain contributor conventions only. Maintainer accounts,
distribution channels, credentials, commands and private strategy belong in
the maintainer's workspace, not this repository.

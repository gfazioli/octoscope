Keyboard shortcuts

octoscope is driven entirely from the keyboard — single characters where possible. The footer always shows the keys that actually work where you are.

Global
1–8 · tabSwitch tab · cycle tabs (⇧tab backwards)
rRefresh now
pToggle public-only mode
%Open the rate-limit detail panel
,Open the settings panel
?Show the keymap overlay
q · ctrl+cQuit
In a list — Repos · PRs · Issues
↑↓ · jkMove up / down
g · GJump to top / bottom
/Filter the list — esc clears it
sCycle the sort order
wCycle work filters — Repos: PRs open · CI broken · stale 90d
EnterOpen the drill-in detail
spaceOpen the row's action menu
o · cOpen on github.com · copy URL
PPin the row (Repos · Issues)
In a drill-in
escBack out one level
o · rOpen on github.com · refresh
vCycle the star-history view — density / cumulative (repo)
cExpand / collapse Checks (repo) · copy URL or path (PR files & diff)
fInspect changed files, then Enter for the diff (PRs)
In the action menu (space)
↑↓ · EnterMove · run the highlighted action
o · d · cOpen on github.com · view details · copy URL
sRun the integrity scan (Repos)
escClose the menu
Scrolling — Overview · Activity heatmap · drill-in body
↑↓Line up / down
pgup pgdn · spacePage up / down
u · dHalf-page up / down
Inbox — read-only
sCycle the filter: all / involving you / ci
/Filter by substring
enter · cOpen the thread on GitHub · copy its link
rReload (it does not ride the dashboard refresh)
Activity — heatmap and feed
←→ · hlSwitch between the heatmap and the feed
↑↓ · gGMove the cursor in the feed · top / bottom
/Filter the feed on anything a row shows
enter · cOpen the event on GitHub · copy its link
rReload the feed (it does not ride the dashboard refresh)
i
